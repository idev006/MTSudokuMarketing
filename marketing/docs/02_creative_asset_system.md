# 02 — Creative Asset System

## Asset Types ต่อ SKU

ทุก SKU ควรมี creative asset อย่างน้อย 3 กลุ่ม:

1. **Cover Prompt หน้า-หลัง**
   - ใช้โปรโมทออนไลน์
   - ใช้เป็นต้นแบบปก Print-on-Demand
   - ต้องรองรับ A4 portrait / 300 dpi / bleed / safe zone

2. **Product Box Prompt**
   - ใช้เพื่อโปรโมทออนไลน์เท่านั้น
   - เป็น digital product box mockup ไม่ใช่กล่องจัดส่งจริง
   - Final recommendation: **vertical 1236 × 2000 px**
   - Golden-ratio inspired ประมาณ 1 : 1.618

3. **Marketing Plan Prompt**
   - ใช้สร้าง social copy, marketplace listing, CTA, bundle และ claim safety

## Visual Communication Rules

Creative ต้องสื่ออย่างชัดเจน:

- Brand: BiiigBee Easy Maths
- 500 Puzzles
- Answer Key Included
- Printable PDF
- Optional Print-on-Demand
- ช่วงชั้น
- Difficulty model
- Mixed Sudoku types

## Online Visual Principles

- อ่านได้บนมือถือ
- Product เด่นแต่ไม่ hard-sell เกินไป
- มีพื้นที่ text-safe zone
- Premium educational publishing look
- เหมาะกับวัยของกลุ่มเป้าหมาย
- ใช้ visual variation ระหว่าง Product Hero / Lifestyle / Parent-Child / Student Activity / Teacher / Challenge / Competition

## Claim Safety

ห้ามใช้:

- ข้อสอบจริง
- official EduPLOYS/Edupoint หากไม่ได้รับสิทธิ์
- รับประกันชนะ
- แนวข้อสอบทางการ

ใช้แทน:

- ชุดฝึกเตรียมแข่งขัน
- training pack
- ฝึกสู่สนามแข่งขัน
- ชุดฝึกอย่างเป็นระบบ
