# Marketing Asset Format Specification

## Book / Interior PDF
- A4 portrait 210 × 297 mm
- 300 dpi สำหรับงานพิมพ์ raster-based assets
- Printable PDF-first

## Cover / POD
Front และ back design area อิง A4 portrait ต่อด้าน แต่ **ห้ามล็อก full-wrap cover เป็น 2480 × 3508 px**

Final POD full-wrap size ต้องคำนวณภายหลังจาก:
- back cover width
- spine width ตามจำนวนหน้าและชนิดกระดาษของผู้ให้บริการ
- front cover width
- bleed / trim requirement ของ printer

ดังนั้น final full-wrap = Back + Spine + Front + Bleed และต้องใช้ template/spec ของ POD provider จริงก่อนส่งพิมพ์

## Product Box Mockup
- vertical
- 1236 × 2000 px
- approximately 1 : 1.618
- golden-ratio inspired
- online promotion only
- ต้องสื่อว่าเป็น digital mockup ไม่ใช่ physical shipping box

## Social
- Feed portrait 4:5
- Square 1:1
- Story/Reel 9:16
