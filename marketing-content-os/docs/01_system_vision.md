# 01 — System Vision

## ชื่อระบบที่เสนอ

**BiiigBee Marketing Content Operating System**

## แนวคิด

> 1 SKU → 1 Campaign Strategy → N Content Rows → Copy + Visual Parameters → Prompt Template Assembly → Review → Publish → Measure

## วัตถุประสงค์

1. ทำให้ผู้ใช้ที่ไม่มีความรู้การตลาดสามารถสร้าง content ได้ง่าย
2. เตรียม content ล่วงหน้าเป็นรายเดือนในครั้งเดียว
3. รักษา brand voice และ positioning
4. ลดการเขียน prompt ภาพซ้ำซ้อน
5. รองรับ prompt ภาพที่ยาวและซับซ้อน
6. รองรับ Google Sheets / CSV / automation ในอนาคต
7. รองรับ campaign memory และ performance feedback loop

## Design Principle

- Stable information → Template
- Variable information → Row Parameters
- Final image prompt → Formula-generated
- General Mode → ใช้ง่าย
- Advanced Mode → override ได้
- Human review ก่อน publish
