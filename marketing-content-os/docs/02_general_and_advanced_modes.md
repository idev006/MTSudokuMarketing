# 02 — General Mode และ Advanced Mode

## General Mode

ออกแบบสำหรับผู้ใช้ที่ไม่มีพื้นฐานการตลาด

### Input ขั้นต่ำ

- SKU
- จำนวนรายการ
- Platform
- ระยะเวลาที่ต้องการใช้

ตัวอย่าง:

```text
SKU: BK-UP-MIX-MEDIUM-01
จำนวน: 20
Platform: Facebook
ระยะเวลา: 1 เดือน
```

ระบบตัดสินใจอัตโนมัติ:

- audience mix
- funnel mix
- content pillar mix
- marketing angle
- CTA distribution
- visual diversity
- campaign sequence
- selling vs educational ratio

## Advanced Mode

ใช้ engine เดียวกับ General Mode แต่เปิด override เช่น:

- campaign theme
- audience mix
- funnel mix
- content mix
- platform mix
- promotion
- CTA style
- visual type mix
- tone
- posting cadence
- preferred / forbidden angles
- campaign objective
- aspect ratio
- previous campaign context

## หลักการสำคัญ

Advanced Mode = General Engine + Override
